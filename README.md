# 企业私有知识库 RAG 实战

从搭建部署到回答校验 · 鲲穹 AI 课堂

**[打开交互课件](https://chengzhuo2025.github.io/kqai-rag-courseware/)**

15 页静态网页课件，包含分步动画、RAG 证据关系演示、来源核验、讲师备注与课堂练习。

方向键 / 空格推进，左下角页码打开目录，底部按钮暂停或重放，设置中可减弱动态。手机支持当前页纵向阅读。

政策、公司和问答均为教学模拟；网页不调用模型。真实操作在 Cherry Studio 中进行。讲师备注及预设答案随静态网页公开。

依赖：Reveal.js 5.2.1、GSAP 3.13.0、Three.js 0.180.0、Lucide 0.468.0。各库许可与说明保留在 vendor/。课件内容、Logo与插画未另行授予开源许可。

发布方式：GitHub Pages 从 main 分支根目录提供静态文件，.nojekyll 停用 Jekyll 处理。
